# Incident: Credential Leak via Textual Snapshot Report

**Date**: 2026-03-11
**Severity**: Low (no exposure)
**Status**: Resolved

## Summary

A GitHub OAuth token (`gho_*`) was captured in `snapshot_report.html` — a Textual test snapshot report that dumps full Python tracebacks with `show_locals=True`. The traceback included `os.environ`, which contained `GITHUB_TOKEN` from the `gh` CLI session.

The file was committed to the `feature/operator-interface-testing` branch but **never reached a remote** — GitHub's push protection blocked the push before any data left the local machine.

## Timeline

| Time (EDT) | Event |
|---|---|
| 2026-03-11 ~21:11 | `snapshot_report.html` committed in `f3f48ce` containing `GITHUB_TOKEN` env var |
| 2026-03-11 ~20:06 | Push to GitHub blocked by push protection (secret scanning) |
| 2026-03-12 ~00:06 | Token identified as `gho_*` (GitHub OAuth, 8-hour TTL, auto-generated by `gh` CLI) |
| 2026-03-12 ~00:06 | Confirmed token expired (~23 hours old, 8-hour TTL) |
| 2026-03-12 ~00:15 | `git-filter-repo` used to scrub `snapshot_report.html` from all branch history |
| 2026-03-12 ~00:15 | `snapshot_report.html` added to `.gitignore` |
| 2026-03-12 ~00:16 | Branch pushed successfully with clean history |

## Blast Radius

- **Token type**: `gho_*` — GitHub OAuth user-to-server token, generated by `gh` CLI
- **Token TTL**: 8 hours (auto-expires)
- **Exposure**: None — push was blocked before the token left the local machine
- **Affected systems**: None
- **Data compromised**: None

## Root Cause

Textual's `show_locals=True` in crash/snapshot reports captures the full Python stack frame, including `os.environ`. When a test crashes or generates a snapshot report, every environment variable — including secrets — is serialized into the HTML output.

The `snapshot_report.html` file was not in `.gitignore`, so it was eligible for `git add`.

## Remediation

### Immediate

1. ✅ Added `snapshot_report.html` to `.gitignore`
2. ✅ Scrubbed file from git history using `git-filter-repo --invert-paths --path snapshot_report.html`
3. ✅ No token rotation needed (expired `gho_*` with 8-hour TTL)

### Preventive

1. ✅ **`.gitignore`**: `snapshot_report.html` excluded from tracking
2. ✅ **TUI crash handler**: `StyreneApp._print_error_renderables()` overridden to write crash tracebacks to a timestamped file in the log directory instead of inline — keeps them out of the working directory where they could be accidentally committed
3. **Recommendation**: Enable GitHub Secret Scanning on the repository (currently disabled per the push protection message) for defense-in-depth on all branches, not just push-time blocking

## Lessons

1. **Any tool that captures `locals()` or `os.environ` in output is a credential leak vector.** Textual's `show_locals=True` is convenient for debugging but dangerous in any file that might be committed. Other examples: Django debug pages, Sentry local variables, pytest `--tb=long` with plugins.

2. **GitHub push protection works.** The secret never left the machine. This is exactly the safety net working as designed.

3. **Short-lived tokens limit blast radius.** The `gho_*` token from `gh` CLI expires in 8 hours. Even if it had been pushed, the window of exploitation would have been narrow. Prefer short-lived tokens over PATs wherever possible.

4. **`.gitignore` is a security control**, not just a convenience. Generated reports, logs, and debug output should be excluded by default.
